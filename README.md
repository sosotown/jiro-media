# ジロラーメン

二郎系ラーメンの食べ歩き記録を届ける編集メディア。

```
                 _,,~~""~~,,_
              ,-"             "-,
             /    JIRO-STYLE     \
            /______________________\
           |  ///// MOYASHI \\\\\\  |
           | ( CABBAGE MOUNTAIN  )  |
           |   CHASHU * NINNIKU     |
            \______________________/
             '-,________________,-'
                    \        /
                     \______/
```

## セットアップ

```bash
npm install
cp .env.example .env.local
npm run dev
```

## ページ構成

- `/` — 記事一覧
- `/articles/[slug]` — 記事詳細
